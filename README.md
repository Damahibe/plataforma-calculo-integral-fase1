# Cálculo Integral: plataforma demostrativa - Fase 1

Ejemplo didáctico para explicar el alcance de la primera fase de una plataforma de cálculo integral. No reemplaza el taller manuscrito ni contiene soluciones de su parte evaluable.

## Arquitectura

- `dist/index.html`: estructura, contenido de los módulos y controles.
- `dist/styles.css`: diseño responsive y accesible.
- `dist/app.js`: cálculos numéricos y gráficos con Plotly.
- Módulos 1 a 6: contenidos y exploradores funcionales.
- Módulos 7 a 14: rutas previstas para fases posteriores.

## Uso local

Abra `dist/index.html` en un navegador con conexión a internet (para Plotly). El sitio puede desplegarse como contenido estático en GitHub Pages o Netlify.

## Uso responsable de IA

Este prototipo fue generado como material orientativo. Si se usa asistencia de IA en la parte de software, el estudiante debe documentarla. El taller de cálculo debe realizarse de forma manuscrita según las instrucciones de la evaluación.
